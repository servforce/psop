## 3. 初赛任务清单

初赛任务以赛事材料为单位，不再把 Skill、Compiler、测试、终端和视频制作步骤拆成独立工单。

- [x] `PRE-01` **比赛报名**（必须）
  - 交付内容：团队及项目报名信息。
  - 完成标准：官网报名记录有效，成员信息准确。

- [ ] `PRE-02` **作品介绍**（必交，500 字以内）
  - 交付内容：项目名称、赛题、目标用户、核心问题、解决方案、创新点、开放复用价值和当前进展。
  - 完成标准：字数合规，评委能快速理解 PSOP 解决什么问题。

- [ ] `PRE-03` **方案 PPT/PDF**（必交）
  - 交付内容：场景价值、用户流程、Agent 能力、技术架构、Demo、数据合规和落地计划。
  - 完成标准：内容完整，并与视频、仓库和技术说明一致。

- [ ] `PRE-04` **Demo 视频**（初赛可选，团队计划提交）
  - 交付内容：Skill 构建、编译、黑盒测试、Rokid 现场运行和 Replay。
  - 完成标准：操作员真实完成组装，关键过程和结果均可验证。

- [ ] `PRE-05` **源代码仓库**（初赛可选，团队计划提交）
  - 交付内容：PSOP 主仓库与 Rokid Android 终端仓库。
  - 完成标准：README、启动方式、依赖、配置、License、开源边界和两个仓库的集成关系清楚，且不包含密钥。

- [ ] `PRE-06` **技术架构说明**（可并入 PPT，团队计划独立准备）
  - 交付内容：Builder、Compiler、Skill Test、Runtime、Rokid Terminal、数据和部署架构。
  - 完成标准：模型、工具、知识、状态主权、外部依赖和可追溯机制说明清楚。

- [ ] `PRE-07` **数据来源与合规说明**（初赛建议说明，复赛必交）
  - 交付内容：机械臂素材、人员拍摄、测试数据、模型、SDK、API 和行业安全边界。
  - 完成标准：每项数据和素材均说明来源、授权、脱敏、用途、保存方式和限制。

- [ ] `PRE-08` **初赛封版与提交**（必须）
  - 交付内容：最终作品介绍、PPT、视频、仓库链接及补充文档。
  - 完成标准：所有链接可访问、版本一致，提交成功并保存回执和最终快照。

## 4. 复赛任务清单

以下任务在初赛入围后启动。

- [ ] `SEM-01` **更新版项目方案**（必交）
  - 完成标准：根据初赛反馈更新场景、流程、Agent 架构、评测指标和落地计划。

- [ ] `SEM-02` **可运行 Demo 或 Demo 视频**（必交）
  - 完成标准：展示输入、Agent 处理、工具或知识调用、结果交付、异常处理和效果验证。

- [ ] `SEM-03` **代码仓库或等价工程材料**（必交）
  - 完成标准：包含运行入口、依赖、配置、示例数据、部署说明、测试方法和运行证据。

- [ ] `SEM-04` **数据来源与合规说明**（必交）
  - 完成标准：完整说明授权、脱敏、隐私、行业风险和专业决策边界。

## 5. 决赛任务清单

以下任务在决赛入围后启动。

- [ ] `FIN-01` **决赛路演 PPT**（必交）
  - 完成标准：形成场景价值、产品、技术、Demo、评测、安全、开放复用和落地的完整叙事。

- [ ] `FIN-02` **现场 Demo**（必交）
  - 完成标准：杭州现场可稳定演示，并准备网络或设备失败时的本地和视频备份。

- [ ] `FIN-03` **项目一页纸与答辩材料**（必交）
  - 完成标准：一页纸信息完整，能够回答行业价值、Agent 必要性、技术深度和安全问题。

- [ ] `FIN-04` **最终代码仓库或交付包**（必交）
  - 完成标准：评审可访问，README、部署说明、示例配置、测试方法和账号说明完整。

## 6. 评审维度对齐

| 评审维度 | 权重 | PSOP 应呈现的内容 |
| --- | ---: | --- |
| 行业场景价值 | 25% | 具体机械臂、操作员和组装任务，以及培训、质量、安全与追溯价值 |
| Agent 能力与任务闭环 | 25% | 人类经验构建、编译、测试、Rokid 运行、验证和 Replay |
| 产品体验与 Demo 完成度 | 20% | 第一视角自然交互、清晰反馈、异常处理和稳定完成任务 |
| 技术实现深度 | 15% | PSOP Skill、PSOP-EG、Agent Harness、Runtime 和多模态证据机制 |
| 安全、合规与可追溯 | 10% | 数据授权、安全门、人工确认、Terminal Event、Trace 和 Replay |
| 开放或复用贡献 | 5% | 开源仓库、部署文档、示例 Skill、测试材料和可复用终端方案 |
