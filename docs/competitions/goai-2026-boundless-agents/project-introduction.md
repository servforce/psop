# PSOP 初赛作品介绍

## 项目信息

| 项目 | 内容 |
| --- | --- |
| 项目名称 | PSOP（Physical Standard Operating Procedure） |
| 行业赛题 | AI+工业制造 |
| 目标用户 | 装备制造与工业生产等涵盖安装、维修等现场作业场景的厂商 |

## 作品介绍

### 项目定位

PSOP 参加“无界应用”AI+工业制造赛题，面向装备制造与工业生产厂商的安装、维修现场。

### 核心问题

现场作业仍依赖 PDF、视频、微信群和老师傅电话沟通，导致经验依赖人传人、执行过程黑盒非标、知识散落难沉淀。

### 解决方案

PSOP 以可执行 Skill 取代静态资料：Builder 智能体从视频、文档、行业标准和专家经验中构建版本化 PSOP Skill，将目标、适用边界、步骤、证据要求、安全约束、异常恢复与完成标准固化为任务契约；Compiler 将其编译为 PSOP-EG。运行时由确定性执行图掌控状态与安全边界，智能体根据现场语音、图像和操作反馈柔性判断；智能眼镜以第一视角逐步引导人员，持续采集多模态证据，异常时暂停、提示或转人工，最终生成可审计的事件、轨迹与回放。

### 创新点

物理任务标准化、PSOP-EG、多模态黑盒时序测试、智能体柔性执行，以及基于现场数据的强化学习反馈。

### 当前进展

项目已打通作业标准化、Skill 构建与测试到眼镜终端运行的闭环。

### 开放/复用价值

项目以 Apache-2.0 协议开源，可复用于装配、巡检、维修、培训等场景，降低培训成本，提升质量一致性与安全可追溯性。
