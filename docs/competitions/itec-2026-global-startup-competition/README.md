# ITEC 2026 全球创业赛

本目录用于保存 PSOP 参加第十四届朝阳国际人才创业大会（ITEC 2026）全球创业赛的相关材料与文档。

## 文档索引

- [比赛简介](competition-overview.md)
- [PSOP 项目报名材料](project-application.md)

建议归档内容包括：

- 官方规则、参赛承诺书及重要通知。
- 参赛赛道选择与资格核验记录。
- 商业计划书、项目简介与申报信息。
- 产品 Demo、演示视频与路演材料。
- 知识产权、团队股权和公司主体证明材料。
- 项目落地朝阳区的规划与资源对接记录。
