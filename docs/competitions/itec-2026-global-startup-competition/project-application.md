## 2. 创业项目概述

以下内容用于报名系统“创业项目概述”字段，提交上限为 1500 字。正式提交时应删除本段说明。

> PSOP（Physical Standard Operating Procedure）是一套面向工业现场的 AI 实时感知与作业指导平台，重点服务工业生产和装备制造中的设备安装、调试、维修、巡检等高专业度、长流程、强安全约束场景。PSOP 可以接入手机、智能眼镜及其他具备摄像头、麦克风、扬声器和显示屏等基础能力的终端设备。终端只是感知、交互和执行的载体；AI 通过终端持续获取现场画面、语音和任务上下文，理解设备、部件、仪表与操作状态，并结合当前作业进度实时提供分步指导、状态确认、风险提醒和异常处置建议，像一位始终在线的现场专家协助工作人员完成作业。
>
> 当前工业现场的作业知识通常分散在纸质或 PDF 版 SOP、设备手册、培训视频、历史工单和老师傅经验中。一线人员一边操作设备，一边翻阅资料或联系远程专家，难以及时获得与现场状态匹配的指导；企业也难以判断关键步骤是否按标准完成、异常如何处置、证据是否完整。这会带来培训周期长、作业质量不一致、异常处理依赖个人经验判定和过程难追溯等问题。
>
> PSOP 的核心在于把实时环境感知与可执行的工业规程结合起来。平台将 SOP、设备资料、行业标准、历史案例和专家经验构建为版本化的“物理世界标准作业流程”，把目标、步骤、证据要求、安全约束、异常恢复和完成标准固化为任务契约。终端采集的现场信息始终与当前步骤及证据要求关联；确定性 Runtime 掌握正式任务状态和安全边界，AI Agent 负责感知理解现场信息。证据不足、条件不符或涉及高风险动作时，系统会要求补充检查、暂停流程或转交人工确认，而不是由大模型自行发散思考，我们称之为“在确定性执行骨架上生长出的柔性智能”。
>
> 对一线人员，PSOP 通过合适的现场终端提供与环境和任务进度同步的操作辅助，减少查找资料和等待专家响应的时间；对企业，PSOP 将优秀技师经验转化为可复制、可测试、可持续更新的数字作业能力，帮助缩短培训周期、提升作业一致性和异常响应效率。系统同步记录关键画面、人员反馈、步骤状态和处置轨迹，任务完成后形成可回放、可审计的运行事实，为质量复盘、安全追溯和流程改进提供依据。
>
> PSOP 已实现从 Skill 构建、黑盒时序测试、到真实现场运行、终端事件采集和运行记录可观测的核心链路。同时支持按设备、工艺和企业标准进行扩展，形成面向安装、维修、巡检和培训等场景的工业 AI 下游解决方案。

## 5. 参赛核心需求

以下内容用于报名系统“核心需求”字段，提交上限为 500 字，可根据实际情况删改：

> 项目希望重点对接工业生产和装备制造企业的真实现场作业场景，围绕设备安装、调试、维修和巡检开展联合试点，获得可用于验证产品价值的 SOP、设备资料、历史工单和经授权脱敏的现场数据；对接中关村（朝阳）工业 AI 产业园及相关工业 AI 服务平台、技术专家和产业导师，完善场景方案、数据安全与商业模式；对接工业数字化渠道伙伴、设备制造商及投资机构，推动首个标杆项目落地，并根据项目发展需要获得办公空间、企业服务、人才招聘和融资支持。
