## 2. 筛选标准

适合 PSOP 的视频应尽量满足：

- 目标是一个明确、可完成的现实任务，而不是纯理论讲解或产品宣传。
- 手、工具、零件、接口和操作位置清楚可见。
- 操作有稳定先后关系，能够拆成准备、执行、检查、纠错和完成确认。
- 能定义可观察的完成标准，例如柜门缝隙均匀、网线测试通过、漏水停止或设备识别到内存。
- 能提取证据要求和安全约束，而不是只给出操作动作。
- 优先选择约 5—15 分钟且信息密度稳定的视频；低于 2 分钟的内容通常只能作为动作补充或对照。
- 在任务覆盖接近时，优先厂商服务账号、品牌工具账号、专业安装或维修机构，并核验账号主体；降低个人泛教学、随手拍和口语化讲解的优先级。
- 最好短于 30 分钟。当前视频分析代码对超过 30 分钟的视频会降采样，并提示局部操作细节可能覆盖不足。
- 避免纯动画、软件仿真、开箱测评、大量跳剪、无讲解短片和多小时课程。

候选等级含义：

| 等级 | 含义 |
| --- | --- |
| A | 任务结构清楚，适合优先完整观看并尝试导入 PSOP |
| B | 有价值，但必须先确认关键画面、安全说明、型号适用范围或是否存在跳步 |
| C | 适合作为补充、对照或失败样本，不建议作为第一批主素材 |

### 3.1 各方向的筛选重点

- **零部件安装**：优先选择从配件清点开始、安装后有稳定性或功能测试的视频；排除只拍完成效果的开箱视频。工业机器人涉及吊装、地脚固定、动力接线和安全联锁；智能锁涉及门体适配、应急开锁和安防；壁挂置物架涉及墙体材质、隐蔽管线和锚固承重，均需单独设置安全边界。
- **日常维护**：优先选择维护周期、耗材型号、停机状态、清洁范围和恢复运行都清楚的视频；排除用不明清洁剂或润滑剂的内容。
- **低风险维修**：只收录普通用户在明确安全边界内可操作的任务。涉及市电、燃气、高压、制冷剂或关键承重结构的维修不归入此类。
- **设备检查**：应能形成检查清单和明确结论，不能只是围绕设备拍摄一圈或口头声称“没有问题”。
- **标准操作**：优先选择来自厂商、培训机构或有明确作业标准的教程，并关注参数、工具和质量判定是否可量化。
- **故障排查**：必须保留排查路径。只有“更换某个零件”的视频属于维修演示，不能直接当作故障排查教程。

## 5. 各任务的 PSOP 适配分析

### 5.1 显示器机械臂安装

候选：`BV1jKzcYKE6B`、`BV19WfMYvE4n`

- 适配原因：零件识别、桌板固定、立柱或支臂连接、显示器挂装、承重调节和理线可形成明确时序。
- 拟拆分步骤：清点零件与工具 → 确认桌板和显示器兼容性 → 固定底座 → 连接支臂 → 安装 VESA 板和显示器 → 调节阻尼/高度 → 检查紧固和稳定性。
- 证据建议：桌板厚度或安装位置照片、底座紧固照片、VESA 螺钉照片、显示器稳定悬停照片。
- 风险点：显示器跌落、桌板承重不足、螺钉长度不合适、夹手。
- 人工复核：确认视频是否展示了防跌落措施、承重范围和最终稳定性检查。

### 5.2 3D 打印机喷嘴更换与调平

- 拟拆分步骤：确认机型和喷嘴规格 → 退料/停机或按厂商要求预热 → 拆卸护罩与喷嘴 → 安装并按要求紧固 → 恢复部件 → 调平/Z 轴校准 → 试打并检查首层。
- 证据建议：机型和喷嘴规格照片、拆卸前状态、安装后喷嘴照片、调平界面或调平纸阻力、首层打印照片。
- 风险点：热端烫伤、喷嘴滑牙、冷态强拆、型号不兼容、树脂接触风险。

- 拟拆分步骤：识别机型和滤芯 → 关闭进水/电源并泄压 → 记录滤芯顺序 → 拆除旧滤芯 → 检查和安装密封件 → 装入新滤芯 → 通水检漏 → 冲洗 → 重置寿命提示。
- 证据建议：型号铭牌、滤芯编号与顺序、密封圈、安装完成状态、通水后无渗漏视频或照片。

- 人工复核：确认视频是否覆盖泄压、冲洗和漏水检查，而不是只展示拆装。

- 拟拆分步骤：识别刹车类型 → 检查碟片/刹车块状态 → 定位蹭碟或制动力不足原因 → 调整卡钳/线张力/行程 → 空转检查 → 低速制动测试。

- 风险点：刹车属于安全关键部件；错误使用润滑剂、螺栓未锁紧或测试不足可能导致事故。
- 人工复核：必须由熟悉自行车维修的人确认教程没有错误涂油、漏掉扭矩要求或混用不同刹车结构。不能只凭模型分析直接用于现场指导。

## 6. 推荐导入顺序

建议不要一次把所有视频导入。先用三个难度梯度建立基线：

1. **低风险、结果明确**：游标卡尺测量、柜门铰链调整或网线水晶头制作。
2. **中等复杂度、涉及检查或复测**：3D 打印机验机、扭矩扳手使用、显示器机械臂安装或净水器滤芯更换。
3. **安全约束和设备状态较多**：万用表、电钻、3D 打印机换喷嘴、自行车刹车调整、显卡/散热器更换、笔记本拆机或智能锁安装。工业机器人本体安装属于专业高风险任务，应单独评审，不进入普通用户首轮导入序列。

每条视频导入前建议人工完整观看一次，并记录：

- 是否是真实连续操作，是否存在大量跳剪。
- 关键动作是否被手、字幕或镜头切换遮挡。
- 讲解和画面是否同步。
- 是否说明前置条件、工具、型号边界和安全要求。
- 是否展示最终验收，而不是在最后一个动作后直接结束。
- 是否包含错误操作、广告段、无关片段或可能误导模型的字幕。

## 7. PSOP 验证建议

对首批视频至少检查以下产物：

| 检查项 | 合格标准 |
| --- | --- |
| ASR 文本 | 关键零件名、动作、警告和顺序基本正确 |
| 关键帧 | 覆盖准备、主要动作、关键检查和完成结果，不只覆盖成品画面 |
| Skill 步骤 | 每一步包含动作对象、前置条件和可观察结果 |
| 安全约束 | 断电、关水、防烫、防跌落或制动安全等没有遗漏 |
| 型号边界 | 具体机型教程没有被无条件泛化到所有设备 |
| 完成标准 | 有最终验证，不能把“动作做完”直接等同于“任务成功” |
| 异常处理 | 至少覆盖装不上、检测失败、渗漏、蹭碟或结果不达标时的处理方向 |

可用同一任务的两条视频做交叉对照：先分别生成 Skill，再比较步骤、警告和完成标准的差异。若两条来源冲突，应由人工或厂商手册裁决，不能简单让模型多数表决。
